# Code of Conduct

## Our standard

Everyone participating in this project — in issues, pull requests, reviews and
discussions — is expected to:

- Be respectful. Disagree with code and ideas, not with people.
- Assume good faith, especially with first-time contributors.
- Keep feedback specific and actionable; "this breaks on input X" beats "this is bad".
- Accept review decisions gracefully; maintainers accept being questioned graciously.

Unacceptable behavior includes harassment, insults or put-downs, publishing others'
private information, sustained disruption, and sexualized or discriminatory language
or imagery. This applies in all project spaces and when representing the project
elsewhere.

## Enforcement

Report violations through [GitHub's report-abuse flow](https://github.com/contact/report-abuse)
or by opening an issue addressed to the maintainers (for sensitive reports, use
GitHub's private vulnerability reporting form on this repo — it reaches the same
people confidentially). Maintainers will review every report, may remove comments,
close threads, or ban repeat offenders from the project, and will keep reporters'
identities confidential where possible.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
